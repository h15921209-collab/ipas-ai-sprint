科目一：人工智慧基礎概論（核心考點與易錯 PK）

13:30 ~ 14:45

01. 學習範式混淆大對決

常考必錯

絕大多數考生容易將 KNN 與 K-Means 搞混，或誤將降維演算法當成分類器：

KNN (K最近鄰)
類型：監督式學習（Supervised）
特點：依據有標籤鄰居多數決，可用於分類與回歸，屬於惰性學習（Lazy Learning）。
K-Means (K平均分群)
類型：非監督式學習（Unsupervised）
特點：無任何標籤，依據特徵距離將資料劃分為 K 個群集（Clustering）。
⚠️ 破題防坑：
PCA（主成分分析）為「非監督式」特徵降維，尋找最大變異數方向；強化學習（RL）則是透過 Agent 與環境互動，依靠「獎勵信號（Reward）」而非標籤。

02. 擬合狀態與偏差方差權衡

高頻計算
過擬合 (Overfitting)
現象：訓練集極高分、驗證集低落。
本質：High Variance（高變異數），死記雜訊。
解法：L1/L2 正則化、Dropout、Early Stopping、增加資料。
欠擬合 (Underfitting)
現象：訓練集低分、驗證集也低分。
本質：High Bias（高偏差），學力不足。
解法：增加模型複雜度、增加特徵、減少正則化強度。
⚠️ L1 vs L2 考法：
L1 Lasso 容易使不重要特徵權重歸零，產生「稀疏矩陣（Sparse）」，可用於特徵選擇；L2 Ridge 則是將權重均勻縮小但保留，抑制過大權重。

03. 混淆矩陣指標秒殺口訣

大考必出
Accuracy = (TP + TN) / Total
Precision = TP / (TP + FP) [預測為正當中，真為正]
Recall = TP / (TP + FN) [真實為正當中，抓出正]
F1-Score = 2 * (Precision * Recall) / (Precision + Recall)
看 Recall (召回率) 的場景
情境：漏抓（FN）代價極慘重！
案例：癌症篩檢、金屬裂紋瑕疵檢測、防盜警報。口訣：「寧可抓錯十個，不能漏放一個！」
看 Precision (精確率) 的場景
情境：誤判（FP）代價極高！
案例：垃圾郵件過濾（絕不能把重要合約丟垃圾桶）、廣告精準推薦、高額交易詐欺攔截。
⚠️ Accuracy 失真陷阱：
當樣本極度不平衡（如 99% 良品、1% 瑕疵品），盲猜全良品準確率即有 99%，此時 Accuracy 完全失真，必須看 Recall 或 F1-Score。

04. 深度神經網路三巨頭架構

架構必考
  • 🖼️ CNN (卷積網路)：影像首選！依賴「局部感受野（Local Receptive Field）」與「權重共享（Weight Sharing）」，具備平移不變性。
  • ⏳ RNN / LSTM (循環網路)：處理前後時序資料（音訊、時間序列）。RNN 容易梯度消失；LSTM 透過「遺忘門、輸入門、輸出門」記住長期記憶。
  • ⚡ Transformer：徹底摒棄遞迴循環！依靠「Self-Attention（自注意力機制）」與位置編碼（Positional Encoding），實現全面並行計算。

05. 活化函數與優化器陷阱

底層原理
Sigmoid 缺點
輸出在 (0, 1)。兩端飽和導致導數接近 0，在深層網路反向傳播時必定引發「梯度消失（Vanishing Gradient）」。
ReLU 優點與死穴
f(x) = max(0, x)。x>0 導數恆為 1，極快且無梯度消失；但 x<0 梯度為 0，可能出現「神經元死亡（Dying ReLU）」。
⚠️ 優化器常識：
Softmax 常用於多分類輸出層（將輸出轉為機率總和為 1）。Adam 結合了動量（Momentum）與自適應學習率（RMSProp），是目前業界最常見的預設優化器。

06. AI 法規治理與風險分級

新法規必考

歐盟《AI Act (人工智慧法案)》採四級風險管制，為全球法規基準：

🚫 不可接受風險 (Unacceptable)：【全面禁止】如社會信用評分、利用潛意識認知操縱脆弱群體。
⚖️ 高風險 (High Risk)：【嚴格合規審查】醫療診斷、求職面試履歷篩選、司法評估、關鍵基建。
💬 有限風險 (Limited Risk)：【透明度義務】聊天機器人、AI 生成影音/Deepfake 必須明確告知使用者為 AI 生成。
🟢 極小風險 (Minimal Risk)：【無限制】垃圾郵件過濾、AI 電玩遊戲。

科目二：生成式AI應用與規劃（核心考點與易錯 PK）

15:15 ~ 16:30

01. 生成式主流架構對抗

生成原理
GAN (生成對抗網路)
架構：生成器 vs 鑑別器雙人零和博弈。
優缺點：生成速度快、細節銳利；但訓練極不穩定，常發生「模式崩潰（Mode Collapse，只生成少數重複樣本）」。
Diffusion (擴散模型)
架構：前向逐步加高斯噪聲，反向神經網路去噪還原。
優缺點：生成多樣性與穩定性極佳（Stable Diffusion/Midjourney 核心）；但多步採樣推論耗時長。
⚠️ LLM 本質：
GPT 等大型語言模型多屬「自回歸模型（Autoregressive）」，本質是根據前文序列預測「下一個 Token 的機率分佈」。

02. 提示工程 (Prompt Engineering) 技術譜系

高頻技巧
  • 🎯 Zero-shot vs Few-shot：零樣本（不給範例直接問） vs 少樣本（給出 2~3 個輸入輸出示範以鎖定語氣與格式）。
  • 🧠 CoT (Chain-of-Thought 思維鏈)：口訣「讓我們一步一步思考」，引導模型輸出中間推導過程，大幅降低數學與邏輯推理錯誤。
  • 🛠️ ReAct (Reason + Act)：模型結合推理與外部工具調用（例如：思考 -> 搜尋資料庫 -> 觀察結果 -> 總結回答）。
  • 🛡️ 格式約束防禦：指定 JSON 格式輸出，並明訂約束條件「若知識庫查無結果請回答不知道，嚴禁自行揣測」。

03. 落地終極抉擇：Prompt vs RAG vs Fine-Tuning

企業規劃大題

這是 IPAS 規劃師最具鑑別度的情境題，牢記三大技術的選型邊界：

1. Prompt Engineering：通用任務、原型驗證、無需外部私有資料、零訓練成本。
2. RAG (檢索增強生成)：【企業知識庫首選！】外部私有文件、經常變動的最新資料、必須精確標註法規引用來源、成本適中、能根本性防範幻覺。
3. Fine-Tuning (微調)：改變模型固有說話語氣/風格、學習特殊代碼/法律專用術語結構、提升特定封閉任務準確度、節省 Prompt Token 長度。需要大量專業數據與 GPU 算力。

04. 輕量微調技術：PEFT 與 LoRA 原理

高分考點
全參數微調 (Full FT)
更新百億甚至千億級所有權重參數，需要巨額顯存（幾十張 A100）且可能導致「災難性遺忘（Catastrophic Forgetting）」。
LoRA (低秩適應)
原理：凍結原預訓練主幹權重，僅在旁支插入低階分解矩陣（B × A）進行訓練。
優點：訓練參數 < 1%，省顯存 80% 以上，微調後可直接合併原權重，推論零延遲。

05. RAG 核心三步與向量檢索實務

技術細節
1️⃣ Indexing (索引階段)：文件讀取 -> 切塊 (Chunking) -> 調用 Embedding 模型轉換成數值向量 -> 存入向量資料庫（如 Milvus, Pinecone, Chroma）。
2️⃣ Retrieval (檢索階段)：提問轉向量 -> 計算餘弦相似度 (Cosine Similarity) -> 檢索 Top-K 相關段落。
3️⃣ Generation (生成階段)：將問題 + 檢索段落拼成 Prompt 餵給 LLM 生成。
⚠️ 切塊策略陷阱：
Chunk 切過大會帶來過多無關雜訊、稀釋語義；切過小則缺乏完整上下文脈絡。通常搭配滑動窗口重疊（Chunk Overlap）保留前後語義。

06. 生成式 AI 安全威脅與參數調校

實務必出
💥 提示注入 (Prompt Injection)：外部惡意輸入透過覆蓋指示搶奪模型控制權（如「忽略前述指示」）。
🔓 越獄攻擊 (Jailbreak)：透過假設情境、虛構故事誘使模型突破安全對齊機制。
👻 幻覺 (Hallucination)：模型給出看似合理卻完全虛構的錯誤答案。對策：RAG 錨定、將 Temperature 調至極低（0.0 ~ 0.2）。
🎛️ Temperature (溫度參數)：高溫（0.8~1.0）多樣發散，適合創意發想；低溫（0~0.2）收斂確定，適合法規、代碼、精準查核。
